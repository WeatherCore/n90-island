# Description

## 中文版

N90 环岛之旅是浏览器 3D 开放世界驾驶游戏：程序化海岛上驾驶小米 N90 MAX 环岛、钓鱼、露营、越野、跑计时赛；由 33.6MB 单文件逆向重构为 Vite + React + TS + three.js 工程，888KB JS（gzip 247KB）1:1 复刻原版。含金量：种子化噪声世界生成令地形植被跨设备逐点一致；命令式引擎与 React 双层架构，每帧 HUD 数值直写 DOM 旁路渲染保 60fps；实例化植被与 Canvas 程序化贴图零美术资产依赖；WebAudio 16 步音序器全合成配乐；localStorage + IndexedDB 双持久化存档与相册；Activities.reward() 统一任务收口。适合作为 three.js 开放世界工程化参考实现。

## English

n90-island is a browser-based 3D open-world driving game: cruise, fish, camp, go off-road and race time trials on a procedurally generated island in a Xiaomi N90 MAX. It is a ground-up rebuild of a 33.6 MB single-file page into Vite + React 18 + TypeScript + three.js — 888 KB of JS (247 KB gzipped) reproducing the original experience 1:1. The engineering core: seeded noise-based world generation keeps terrain and vegetation layouts bit-identical across devices; an imperative engine layer sits beneath a React shell, with per-frame HUD numbers written straight to the DOM to bypass React re-renders at 60 fps; instanced procedural vegetation and Canvas-generated textures eliminate baked art assets; a WebAudio 16-step sequencer synthesizes the entire soundtrack; localStorage and IndexedDB dual persistence back the save system and a photo album; and a single Activities.reward() gateway funnels all quest completions. A solid reference for engineering three.js open worlds.
